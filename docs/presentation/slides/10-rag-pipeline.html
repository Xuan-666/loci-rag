02 · 系统设计 → RAG 检索流水线

6 步流水线 + 智能 Fallback

从用户问题到最终答案，Loci 走完「混合检索 → 精排 → 阈值过滤 → Fallback 决策 → LLM 生成 → 流式输出」6 个阶段。

Step 01
⌕
混合检索
BM25 召回 Top20 + FAISS 向量召回 Top20，RRF 融合后输出 Top20 候选。
BM25:0.6 · Vector:0.4
Step 02
⟁
Rerank 精排
CrossEncoder (bge-reranker-base) 对 40 个候选打分，输出 Top10。
initial_k=40 · final_k=8
Step 03
⊘
阈值过滤
过滤掉 sigmoid 分数 < 0.3 的低质匹配，避免污染 LLM 上下文。
RERANK_SCORE_THRESHOLD=0.3
Step 04
⌥
Fallback 决策
过滤后若无结果且最高分 < 0.5，自动切到纯 LLM 路径。
RAG_FALLBACK_THRESHOLD=0.5
Step 05
✎
LLM 生成
LCEL 链：prompt(system+context+history+q) → ChatOllama → StrOutputParser。
deepseek-r1:7b · LCEL
Step 06
⤓
SSE 流式输出
逐 token yield，前端 fetch().body.getReader() 实时渲染。
events: sources → token* → done
// FALLBACK
RAG Fallback 智能兜底
当知识库无相关答案时，自动切到纯 LLM 路径，用黄色提示条告知用户「答案未参考文档」。
RAG_FALLBACK_ENABLED = True
