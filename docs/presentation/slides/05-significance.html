为什么需要本地 RAG？

云端 RAG 服务存在隐私、成本、网络依赖三大硬伤，Loci 用「本地化 + 混合检索 + 智能 Fallback」给出回应。

云端 RAG
// Common Cloud Pattern
  • 数据隐私文档上传到第三方服务器，企业敏感数据有泄露风险
  • 持续成本按 token 计费 + 向量库订阅费，月均 ¥200-2000+
  • 网络依赖断网/限速/服务宕机时直接不可用
  • 黑盒检索用户无法干预检索策略与排序逻辑
  • 格式受限多数 SaaS 不支持 .doc / .pptx / .rtf 等本地常见格式
